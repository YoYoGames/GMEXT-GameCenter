gamecenter_leaderboard_submit

This function submits a score to a Game Center leaderboard. This is an Apple-only feature (iOS and macOS).

Both score and context are integers.

Note

GameKit leaderboard scores are integer-only; a fractional score or context is truncated. For decimal scores configure a formatter in App Store Connect and submit a scaled integer (e.g. score*100).

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

gamecenter_leaderboard_submit(leaderboard_id, score, context, callback)
Argument Type Description
leaderboard_id String The leaderboard's ID as configured in App Store Connect
score Real The score to submit (integer)
context Real An integer value of your choice stored alongside the score
callback Function The function to call when the submission completes


Returns:

N/A


Triggers:

Callback

This callback is triggered when the score submission has completed.

Key Type Description
result GameCenterLeaderboardSubmitResult The struct containing the result of the submission


Example:

gamecenter_leaderboard_submit("my_leaderboard", 1500, 0, function(_result) {
    if (_result.success) {
        show_debug_message($"Submitted {_result.score} to {_result.leaderboard_id}");
    } else {
        show_debug_message($"Submit failed: {_result.error_message}");
    }
});
This code submits a score to a leaderboard and outputs the result in a debug message.

gamecenter_leaderboard_load

This function loads entries from a Game Center leaderboard. This is an Apple-only feature (iOS and macOS).

Ranks are 1-based. range_start is the first rank to fetch (>= 1) and range_count is how many entries to fetch.

Note

GameKit limits a single load to 100 entries — range_count is capped to 1..100.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

gamecenter_leaderboard_load(leaderboard_id, time_scope, range_start, range_count, player_scope, callback)
Argument Type Description
leaderboard_id String The leaderboard's ID as configured in App Store Connect
time_scope GameCenterLeaderboardTimeScope The time scope of the scores to fetch
range_start Real The first rank to fetch (>= 1)
range_count Real The number of entries to fetch (1..100)
player_scope GameCenterLeaderboardPlayerScope Whose scores to fetch
callback Function The function to call when the load completes


Returns:

N/A


Triggers:

Callback

This callback is triggered when the leaderboard entries have finished loading.

Key Type Description
result GameCenterLeaderboardLoadResult The struct containing the loaded leaderboard data


Example:

gamecenter_leaderboard_load("my_leaderboard", GameCenterLeaderboardTimeScope.AllTime, 1, 10, GameCenterLeaderboardPlayerScope.Global, function(_result) {
    if (_result.success) {
        show_debug_message($"Total players: {_result.total_players_count}");
        array_foreach(_result.entries, function(_entry) {
            show_debug_message($"#{_entry.rank}: {_entry.formatted_score} ({_entry.player.display_name})");
        });
    } else {
        show_debug_message($"Load failed: {_result.error_message}");
    }
});
This code loads the top 10 all-time global entries from a leaderboard and outputs them in debug messages.

GameCenterLeaderboardTimeScope

This enumeration contains the time scopes that can be used when loading a leaderboard.

These constants are referenced by the following functions:

  • gamecenter_present_view_leaderboard
  • gamecenter_leaderboard_load


Member Description
Today The leaderboard shows today's scores.
Week The leaderboard shows this week's scores.
AllTime The leaderboard shows all-time scores.

GameCenterLeaderboardPlayerScope

This enumeration contains the player scopes that can be used when loading a leaderboard.

These constants are referenced by the following functions:

  • gamecenter_present_view_leaderboard
  • gamecenter_leaderboard_load


Member Description
Global The leaderboard shows scores from all players.
FriendsOnly The leaderboard shows scores from the local player's friends only.

GameCenterLeaderboardSubmitResult

This struct is passed to the callback of gamecenter_leaderboard_submit and contains the result of a score submission.

This struct is referenced by the following functions:

  • gamecenter_leaderboard_submit


Member Type Description
success Boolean Whether the submission succeeded
error_code Real The error code (only meaningful when success is false)
error_message String A human-readable error message (only meaningful when success is false)
leaderboard_id String The ID of the leaderboard the score was submitted to
score Real The score that was submitted
context Real The context value that was submitted

GameCenterLeaderboardEntry

This struct represents a single entry (a player's score) on a Game Center leaderboard.

This struct is referenced by the following structs:

  • GameCenterLeaderboardLoadResult


Member Type Description
context Real The integer context value that was submitted alongside the score
date Real The date and time the score was submitted, as a GameMaker datetime (-1 if not available)
rank Real The 1-based rank of this entry on the leaderboard
score Real The raw score value
formatted_score String The score formatted according to the leaderboard's formatter in App Store Connect
player GameCenterPlayer The player this entry belongs to (see GameCenterPlayer)

GameCenterLeaderboardLoadResult

This struct is passed to the callback of gamecenter_leaderboard_load and contains the loaded leaderboard data.

This struct is referenced by the following functions:

  • gamecenter_leaderboard_load


Member Type Description
success Boolean Whether the load succeeded
error_code Real The error code (only meaningful when success is false)
error_message String A human-readable error message (only meaningful when success is false)
leaderboard_id String The ID of the leaderboard that was loaded
time_scope Real The time scope that was requested (see GameCenterLeaderboardTimeScope)
range_start Real The first rank that was requested
range_count Real The number of entries that was requested
player_scope Real The player scope that was requested (see GameCenterLeaderboardPlayerScope)
leaderboard_title String The display title of the leaderboard
leaderboard_group String The group identifier of the leaderboard
leaderboard_type Real The type of the leaderboard
leaderboard_start_date Real The leaderboard's start date as a GameMaker datetime (-1 if not available)
leaderboard_next_start_date Real The leaderboard's next start date as a GameMaker datetime (-1 if not available)
leaderboard_duration Real The leaderboard's duration
total_players_count Real The size of the whole leaderboard pool matching the scopes (NOT the number of entries returned)
local_entry GameCenterLeaderboardEntry The local player's own entry (a rank of -1 means the player has no entry in range)
entries Array of GameCenterLeaderboardEntry The array of fetched leaderboard entries
