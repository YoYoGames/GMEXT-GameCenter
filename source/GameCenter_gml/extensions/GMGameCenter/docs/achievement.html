Achievement

This module provides functions for reporting and loading Game Center achievement progress for the local player on the Apple targets (iOS and macOS).

This module reports and loads achievement PROGRESS; it does not expose the achievement catalog metadata (title, description, artwork).

Functions

The following functions are provided to work with achievements:

  • gamecenter_achievement_report
  • gamecenter_achievement_reset_all
  • gamecenter_achievement_load

Structs

The following structs are used by the achievement functions:

  • GameCenterAchievement
  • GameCenterAchievementReportResult
  • GameCenterAchievementResetResult
  • GameCenterAchievementsResult

gamecenter_achievement_report

This function reports progress for a single achievement to Game Center for the local player.

The identifier is the achievement ID you configured for the game in App Store Connect. The percent_complete is the progress to report, given as a whole-number percentage. When the achievement reaches 100% the show_completion_banner argument controls whether Game Center displays its built-in completion banner.

Note

GameKit requires percent_complete to be an integer in the range 0..100; values are clamped to that range and rounded to a whole number. [!NOTE]

This function is only available on the Apple targets (iOS and macOS).

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

gamecenter_achievement_report(identifier, percent_complete, show_completion_banner, callback)
Argument Type Description
identifier String The achievement ID as configured in App Store Connect
percent_complete Real The progress to report, as a whole-number percentage (0..100)
show_completion_banner Boolean Whether Game Center shows the built-in completion banner when the achievement reaches 100%
callback Function The function to call once the report attempt finishes


Returns:

N/A


Triggers:

Callback

This callback is triggered when the achievement report attempt finishes.

Key Type Description
result GameCenterAchievementReportResult A struct containing the result of the report (see GameCenterAchievementReportResult)


Example:

gamecenter_achievement_report("ach_first_win", 100, true, function(_result) {
    if (_result.success) {
        show_debug_message($"Reported {_result.identifier} at {_result.percent_complete}%");
    } else {
        show_debug_message($"Report failed: {_result.error_message}");
    }
});
This code reports an achievement as fully completed and shows the completion banner, outputting the outcome in the callback.

gamecenter_achievement_reset_all

This function resets ALL of the local player's achievements for the game.

Note

This operation is irreversible and clears the progress of every achievement for the local player. It is primarily useful during testing. [!NOTE]

This function is only available on the Apple targets (iOS and macOS).

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

gamecenter_achievement_reset_all(callback)
Argument Type Description
callback Function The function to call once the reset attempt finishes


Returns:

N/A


Triggers:

Callback

This callback is triggered when the reset attempt finishes.

Key Type Description
result GameCenterAchievementResetResult A struct containing the result of the reset (see GameCenterAchievementResetResult)


Example:

gamecenter_achievement_reset_all(function(_result) {
    if (_result.success) {
        show_debug_message("All achievements reset");
    } else {
        show_debug_message($"Reset failed: {_result.error_message}");
    }
});
This code resets all of the local player's achievements and outputs the outcome in the callback.

gamecenter_achievement_load

This function loads all of the local player's achievements, returning their current progress as an array of GameCenterAchievement.

Note

This function reports the local player's achievement PROGRESS; it does not expose the achievement catalog metadata such as title, description or artwork. [!NOTE]

This function is only available on the Apple targets (iOS and macOS).

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

gamecenter_achievement_load(callback)
Argument Type Description
callback Function The function to call once the achievements have loaded


Returns:

N/A


Triggers:

Callback

This callback is triggered when the achievements have finished loading.

Key Type Description
result GameCenterAchievementsResult A struct containing the result of the load (see GameCenterAchievementsResult)


Example:

gamecenter_achievement_load(function(_result) {
    if (_result.success) {
        array_foreach(_result.achievements, function(_ach) {
            show_debug_message($"{_ach.identifier}: {_ach.percent_complete}%");
        });
    } else {
        show_debug_message($"Load failed: {_result.error_message}");
    }
});
This code loads the local player's achievements and outputs each one's progress in the callback.

GameCenterAchievement

This struct represents a single achievement's progress for the local player.

This struct is referenced by the following structs:

  • GameCenterAchievementsResult


Member Type Description
identifier String The achievement ID as configured in App Store Connect
percent_complete Real The current progress as a whole-number percentage (0..100)
is_completed Boolean Whether the achievement is completed (true at 100%)
shows_completion_banner Boolean Whether Game Center shows the built-in completion banner for this achievement
player GameCenterPlayer The local player this achievement belongs to (see GameCenterPlayer)
last_reported_date Real The date the achievement progress was last reported, as a GameMaker datetime

GameCenterAchievementReportResult

This struct contains the result of a gamecenter_achievement_report call.

This struct is referenced by the following functions:

  • gamecenter_achievement_report


Member Type Description
success Boolean Whether the report succeeded
error_code Real The error code (only meaningful when success is false)
error_message String The error message (only meaningful when success is false)
identifier String The achievement ID that was reported
percent_complete Real The progress that was reported, as a whole-number percentage (0..100)
